E5 · SQL oppure Web

Trovare gli ID degli studenti iscritti a SQL oppure Web, inclusi quelli iscritti a entrambi.

Mostra lo svolgimento e il risultato
  1. Ricava gli ID di SQL (Cid 10) e di Web (Cid 20).
  2. I due risultati hanno lo stesso schema (Sid): applica l'unione.
A ← π[Sid](σ[Cid = 10](ISCRIZIONI))
B ← π[Sid](σ[Cid = 20](ISCRIZIONI))
A ∪ B

Controllo: Chi segue entrambi compare una sola volta.

E6 · SQL ma non Web

Trovare gli ID degli studenti iscritti a SQL e non iscritti a Web.

Mostra lo svolgimento e il risultato
  1. Parti dagli iscritti a SQL.
  2. Sottrai gli ID degli iscritti a Web, mantenendo lo stesso schema.
A ← π[Sid](σ[Cid = 10](ISCRIZIONI))
B ← π[Sid](σ[Cid = 20](ISCRIZIONI))
A − B
Risultato di E6: 1 tuple
Sid
3

Controllo: Invertire la differenza darebbe Diego (4), che segue Web ma non SQL.

E7 · SQL e Web

Trovare gli ID degli studenti iscritti sia a SQL sia a Web.

Mostra lo svolgimento e il risultato
  1. Costruisci gli insiemi A e B come negli esempi precedenti.
  2. Interseca i risultati; se vuoi usare soltanto i cinque operatori richiesti, espandi l'intersezione.
A ← π[Sid](σ[Cid = 10](ISCRIZIONI))
B ← π[Sid](σ[Cid = 20](ISCRIZIONI))
A ∩ B = A − (A − B)
Risultato di E7: 3 tuple
Sid
1
2
5

Controllo: Le due iscrizioni sono tuple diverse: σ[Cid = 10 ∧ Cid = 20] non può trovarle in una sola riga.

E8 · Tutte le combinazioni classe-corso

Costruire le combinazioni possibili fra le classi presenti e i corsi SQL o Web. Non si chiedono le iscrizioni effettive.

Mostra lo svolgimento e il risultato
  1. Proietta le classi distinte.
  2. Ricava i codici dei due corsi.
  3. Il prodotto combina ogni classe con ogni codice.
A ← π[Classe](STUDENTI)
B ← π[Cid](σ[Cid = 10 ∨ Cid = 20](CORSI))
A × B
Risultato di E8: 4 tuple
ClasseCid
5A10
5A20
5B10
5B20

Controllo: Il risultato contiene 2 × 2 = 4 possibilità e non registra alcun fatto di frequenza.
